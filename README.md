Personal Portfolio Application
A full‑stack personal portfolio web application showcasing my projects and skills.
Built with React (frontend) and Flask (backend), and deployed on Render.

🚀 Features
Responsive frontend built with reusable React components

Smooth navigation using React Router

RESTful API integration with Flask backend

Basic loading and error handling for API calls

Health monitoring endpoint (/health) for uptime checks

Deployed with separate frontend and backend services on Render

🛠️ Tech Stack
Frontend: React, React Router, HTML, CSS

Backend: Flask (Python), RESTful APIs

Deployment: Render (cloud hosting)

📦 Installation & Setup
Clone the repository:

bash
git clone https://github.com/your-username/portfolio.git
cd portfolio
Install frontend dependencies:

bash
cd frontend
npm install
npm start
Install backend dependencies:

bash
cd backend
pip install -r requirements.txt
flask run
🌐 Deployment
The application is deployed on Render with separate services for frontend and backend.
Health monitoring and uptime checks are enabled to reduce cold‑start latency.
